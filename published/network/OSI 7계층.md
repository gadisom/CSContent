> OSI 7계층은 네트워크 통신 과정을 역할별로 나누어, 데이터가 장비와 프로그램 사이를 어떻게 이동하는지 이해하기 위한 참조 모델이다.

## 정의
- OSI 7계층: 네트워크 통신 과정을 물리, 데이터 링크, 네트워크, 전송, 세션, 표현, 응용 계층으로 나눠 설명하는 참조 모델이다.
- 계층형 모델: 복잡한 통신 과정을 여러 단계로 나누어 각 단계가 맡는 역할을 분리한 구조다. 한 계층은 바로 위 계층에 서비스를 제공하고, 바로 아래 계층의 기능을 사용한다.
- TCP/IP 모델: 실제 인터넷에서 널리 쓰이는 프로토콜 구조다. OSI 7계층을 이해할 때 비교 대상으로 함께 언급되지만, TCP/IP 자체는 별도의 모델로 더 깊게 다룰 수 있다.
- 캡슐화: 송신 측에서 상위 계층 데이터에 하위 계층의 제어 정보를 붙이며 내려가는 과정이다. 수신 측에서는 반대로 각 계층의 정보를 해석하고 제거하며 원래 데이터에 가까워진다.
- 데이터 단위: 물리 계층은 비트, 데이터 링크 계층은 프레임, 네트워크 계층은 패킷, 전송 계층은 세그먼트 또는 데이터그램 단위로 이해하면 흐름이 잡힌다.

## 핵심 포인트
- 1계층 물리 계층은 비트를 전기 신호, 빛, 전파 같은 실제 신호로 바꾸어 매체를 통해 전달한다. 케이블, 랜선, 허브, 리피터, 광케이블처럼 물리적인 연결과 신호 전달을 다룬다.
- 2계층 데이터 링크 계층은 같은 네트워크 안에서 노드 간 데이터를 전달한다. MAC 주소를 사용하고, 데이터를 프레임 단위로 다루며, 기본적인 에러 검출을 수행한다.
- 3계층 네트워크 계층은 서로 다른 네트워크 사이에서 목적지까지 갈 경로를 결정한다. IP 주소와 라우팅이 핵심이며, 라우터는 이 계층의 대표 장비다.
- 4계층 전송 계층은 송신 애플리케이션과 수신 애플리케이션 사이의 데이터 전달을 담당한다. 데이터 분할, 순서 제어, 재전송, 흐름 제어 같은 기능이 이 계층에서 다뤄진다.
- 5계층 세션 계층은 통신을 시작하고 유지하고 종료하는 연결 상태를 다룬다. 사용자가 서비스에 접속해 일정 시간 동안 통신을 이어가는 흐름을 세션 관점에서 볼 수 있다.
- 6계층 표현 계층은 데이터의 표현 방식을 맞춘다. 문자 인코딩, 압축, 암호화, 복호화처럼 한쪽에서 만든 데이터를 다른 쪽이 이해할 수 있는 형식으로 다루는 역할이다.
- 7계층 응용 계층은 사용자가 직접 사용하는 네트워크 기능과 가장 가깝다. 브라우저, 메일, 메신저, API 통신이 여기에 해당하며 HTTP, HTTPS, FTP, SMTP, DNS 같은 프로토콜을 접할 수 있다.
- 데이터는 송신 측에서 응용 계층부터 물리 계층까지 내려가며 각 계층의 정보를 덧붙이고, 수신 측에서는 물리 계층부터 응용 계층까지 올라가며 그 정보를 해석한다.
- 실제 구현에서는 OSI 7계층이 완전히 분리되어 보이지 않을 수 있다. 그래도 계층별 역할을 나눠 이해하면 네트워크 흐름을 단계적으로 파악하기 쉽다.

- MAC 주소 기반 전달은 데이터 링크 계층의 역할일까?
- 라우터는 IP 주소를 보고 목적지까지의 경로 선택에 관여할까?
- TCP는 ACK, 재전송, 순서 보장 같은 신뢰성 기능을 제공할까?
- 암호화, 압축, 인코딩은 표현 계층의 역할로 볼 수 있을까?
- HTTP 요청은 응용 계층에서 다루는 대표 사례일까?
