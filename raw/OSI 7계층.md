### 1. 물리 계층 (Physical Layer) 
역할 - 0과 1을 실제 전기 신호로 변환해서 전달 
하는 일 
- 케이블 
- 랜선 
- 허브 
- 리피터
- 광케이블 
등 실제 하드웨어를 통해 데이터를 전달 

데이터 단위 
Bit - 10101010 

예시 
랜선을 뽑으면 인터네싱 안되는 이유- 물리 계층 문제 

### 2. 데이터 링크 계층 (Data Link Layer) 
역할 - 같은 네트워크 내에서 안전하게 데이터 전달 
하는 일 
- MAC 주소 사용 
- 에러 검출 
- 프레임 생성
데이터 단위 
MAC주소 데이터

장비 - 스위치 
예시 
회사 와이파이에 연결된 A 컴퓨터 -> B 컴퓨터 전달 
대표 프로토콜 - Ethernet 

--- 
### 네트워크 계층 (Network Layer) 
역할 - 목적지까지 경로를 찾는다 

하는 일 
- IP 주소 사용 
- 라우팅 
- 최적 경로 선택 

데이터 단위 = ip 주소 - 데이터 

장비 - 라우터 
대표 프로토콜 - IP, ICMP 
예시 ) 서울->  부산 어떤 경로로 갈지 결정 

---
### 4. 전송 계층 (Transport Layer) 
역할 - 데이터를 정확하게 전달 

하는일 - 데이터 분할, 순서 보장, 재전송, 흐름제어 

데이터 단위 -segment 

대표 프로토콜 TCP 신뢰성 보장 
보냄
↓
받음 확인(ACK)
↓
다음 데이터

UDP 확인 한함 - 그냥 보냄 

### **예시**

TCP

- 웹
- 로그인
- 결제

UDP

- 게임
- 영상 스트리밍
- 실시간 통화
