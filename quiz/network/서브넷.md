#### 객관식 | [578]
서브넷 마스크의 역할로 가장 알맞은 것은?
1. 포트 번호를 구분한다
2. ✅ 서브넷 마스크는 네트워크/호스트 비트를 구분한다
3. MAC 주소를 암호화한다
4. DNS 질의를 대체한다
> 서브넷 마스크는 IP 주소에서 네트워크 영역과 호스트 영역을 나누는 기준입니다.

#### OX | [579]
CIDR 표기법은 IP 블록 크기를 표현하는 방식이다.
> O
> CIDR은 /24처럼 네트워크 prefix 길이를 표현해 IP 블록의 크기와 범위를 나타냅니다.
