#### 객관식 | [506]
OSI 7계층에서 HTTP가 동작하는 계층은?
1. 전송 계층
2. 네트워크 계층
3. ✅ 응용 계층
4. 세션 계층
> HTTP는 사용자가 직접 접하는 네트워크 서비스와 가까운 7계층 응용 계층에서 다룹니다.

#### OX | [700]
물리 계층은 0과 1을 실제 전기 신호나 빛 같은 물리적 신호로 바꿔 전달하는 계층이다.
> O
> 랜선, 케이블, 허브, 리피터처럼 실제 하드웨어를 통한 전달은 물리 계층과 관련이 깊습니다.

#### 빈칸 | [701]
같은 네트워크 안에서 장비를 식별하고 프레임을 전달할 때 주로 사용하는 주소는 ____ 주소다.
> MAC
> 데이터 링크 계층은 같은 네트워크 안에서 MAC 주소를 이용해 프레임 전달을 다룹니다.

#### 객관식 | [702]
IP 주소를 기준으로 목적지까지의 경로를 선택하는 계층은?
1. 데이터 링크 계층
2. ✅ 네트워크 계층
3. 표현 계층
4. 응용 계층
> 네트워크 계층은 IP 주소와 라우팅을 통해 목적지까지 갈 경로를 결정합니다.

#### OX | [703]
TCP는 전송 계층에서 동작하며, 데이터 순서 보장과 재전송 같은 신뢰성 기능을 제공한다.
> O
> TCP는 전송 계층의 대표 프로토콜이며 ACK, 재전송, 순서 보장 등을 통해 신뢰성을 높입니다.

#### 빈칸 | [704]
데이터의 암호화, 복호화, 압축, 인코딩처럼 데이터 형식을 맞추는 역할은 ____ 계층과 관련이 깊다.
> 표현
> 표현 계층은 응용 계층이 이해할 수 있도록 데이터의 표현 방식과 형식을 다룹니다.

#### 객관식 | [705]
OSI 7계층을 사용하는 주된 이유로 가장 적절한 것은?
1. 모든 네트워크 장비가 반드시 7개 부품으로 나뉘기 때문
2. ✅ 통신 과정을 역할별로 나누어 이해하고 문제를 추적하기 쉽기 때문
3. TCP보다 UDP를 항상 빠르게 만들기 때문
4. 데이터베이스 조회 속도를 높이기 때문
> OSI 7계층은 실제 구현을 그대로 강제하는 모델이라기보다, 통신 과정을 역할별로 나눠 이해하기 위한 참조 모델입니다.
