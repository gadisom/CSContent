#### OX | [502]
TCP는 연결 지향적이며 데이터 전달의 신뢰성을 보장한다.
> O
> TCP는 연결 수립 후 ACK, 시퀀스 번호, 재전송 등을 통해 데이터 전달의 신뢰성을 높입니다.

#### 객관식 | [503]
TCP가 데이터 전달의 신뢰성을 높이기 위해 사용하는 방식으로 가장 거리가 먼 것은?
1. 수신 확인 ACK를 바탕으로 도착 여부를 확인한다
2. 손실된 데이터를 재전송한다
3. 시퀀스 번호로 데이터 순서를 맞춘다
4. ✅ 포트 번호만으로 데이터 순서를 보장한다
> 포트 번호는 같은 호스트 안에서 애플리케이션을 구분하는 값입니다. TCP의 순서 보장은 시퀀스 번호와 ACK 등을 통해 이뤄집니다.
