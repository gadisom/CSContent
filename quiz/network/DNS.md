#### 빈칸 | [508]
DNS의 역할은 도메인 이름을 컴퓨터가 찾을 수 있는 ___ 로 변환하는 것이다.
> 주소
> DNS(Domain Name System)는 사람이 읽기 쉬운 도메인을 컴퓨터가 사용하는 IP로 변환합니다.

#### 객관식 | [572]
DNS에 대한 설명으로 가장 알맞은 것은?
1. 패킷 암호화를 수행한다
2. 라우팅 경로를 계산한다
3. 포트 번호를 할당한다
4. ✅ 도메인 이름을 IP 주소로 변환한다
> DNS는 인터넷의 전화번호부 역할을 합니다.

#### OX | [573]
DNS 조회 결과는 캐시를 통해 재사용될 수 있다.
> O
> DNS는 인터넷의 전화번호부 역할을 합니다.

#### 빈칸 | [574]
DNS 레코드는 도메인을 컴퓨터가 찾아갈 수 있는 ___ 에 연결한다.
> 주소
> A 레코드는 도메인을 IPv4 주소에 매핑합니다. IPv6는 AAAA 레코드를 사용합니다.

#### 객관식 | [718]
DNS 조회에서 권한 있는 네임서버의 역할로 가장 적절한 것은?
1. 브라우저 화면을 렌더링한다.
2. TCP 연결을 직접 수립한다.
3. ✅ 특정 도메인의 실제 DNS 레코드를 관리한다.
4. HTTP 요청 본문을 암호화한다.
> 권한 있는 네임서버는 특정 도메인 영역의 DNS 레코드에 대한 최종 정보를 제공합니다.

#### OX | [719]
DNS 응답은 TTL 동안 캐시되어 반복 조회를 줄일 수 있다.
> O
> TTL은 DNS 응답을 캐시에 얼마나 오래 보관할 수 있는지 나타내며, 조회 시간과 트래픽을 줄이는 데 도움을 줍니다.

#### 빈칸 | [720]
도메인을 IPv4 주소에 연결하는 대표 DNS 레코드는 ____ 레코드다.
> A
> A 레코드는 도메인 이름을 IPv4 주소에 매핑합니다.

#### 객관식 | [721]
재귀 해석기에 대한 설명으로 가장 적절한 것은?
1. 사용자의 HTML을 직접 생성한다.
2. ✅ 클라이언트 대신 최종 DNS 응답을 찾아주는 서버다.
3. 서버의 개인키를 보관하는 저장소다.
4. IP 패킷의 최단 경로를 계산하는 라우터다.
> 재귀 해석기는 클라이언트 요청을 받아 필요한 DNS 서버들을 조회하고 최종 응답을 돌려줍니다.

#### OX | [722]
DNS 조회가 실패하면 웹 서버가 정상이어도 도메인 이름으로 접속하지 못할 수 있다.
> O
> 도메인을 IP 주소로 해석하지 못하면 브라우저는 어떤 서버로 연결해야 하는지 알기 어렵습니다.

#### 빈칸 | [723]
도메인 별칭을 다른 도메인 이름으로 연결하는 DNS 레코드는 ____ 레코드다.
> CNAME
> CNAME 레코드는 하나의 도메인 이름을 다른 도메인 이름의 별칭으로 연결합니다.
