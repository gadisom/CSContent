#### 객관식 | [740]
Copy-on-Write에 대한 설명으로 가장 알맞은 것은?
1. 값을 대입할 때마다 항상 전체 데이터를 즉시 복사한다
2. class 인스턴스를 자동으로 weak 참조로 바꾼다
3. ✅ 저장소를 공유하다가 변경이 필요할 때 복사해 값 타입의 의미를 유지한다
4. Optional을 자동으로 언래핑한다
> Copy-on-Write는 Array, Dictionary 같은 값 타입 컬렉션에서 불필요한 복사를 줄이면서 변경 시 독립성을 지키는 최적화입니다.

#### 객관식 | [741]
공유 mutable state가 많아질 때 참조 타입에서 특히 주의해야 하는 문제로 가장 알맞은 것은?
1. 모든 값이 자동으로 nil이 된다
2. ✅ 여러 곳에서 같은 상태를 바꾸며 메모리 관리나 동시성 문제가 생길 수 있다
3. 컴파일러가 모든 변경을 금지한다
4. Equatable을 절대 구현할 수 없다
> 참조 타입은 같은 인스턴스를 여러 곳에서 공유할 수 있어 ARC, retain cycle, 동시 접근 같은 문제를 함께 고려해야 합니다.
